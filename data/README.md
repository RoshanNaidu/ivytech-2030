# data/

Drop the files provided on challenge day here (CSV, XLSX, JSON, Parquet, TSV). They appear automatically in
the app's sidebar **Dataset** picker. Everything in this folder except this README is **git-ignored**, because
it may contain student records. Do not commit raw data. If the organisers say a dataset is public and small,
commit it deliberately with `git add -f`.
