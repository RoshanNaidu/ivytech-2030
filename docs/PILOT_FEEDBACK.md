# Pilot feedback (Phase 3)

## Questions to ask each pilot user (2 minutes)
1. What did you expect to happen when you first opened it?
2. Could you complete <the core task>? Where did you hesitate?
3. On a scale of 1-5, how useful would this be in your real week? Why not a 5?
4. What is the one thing you would change?
